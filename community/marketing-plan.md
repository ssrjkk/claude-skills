# Claude Skills Library — Marketing Plan

## Platform Strategy

### Habr (Russian)
- **Title**: "Как я создал библиотеку из 10,000 навыков для Claude Code"
- **Angle**: Путь разработчика, технические детали, вызовы
- **Sections**: 
  - Проблема: каждый раз писать одинаковые промпты
  - Решение: структурированные навыки с YAML frontmatter
  - Масштабирование: от 100 до 10,000 навыков
  - Двуязычность: почему это важно для RU-сообщества
  - Архитектура: Python SDK, quality scoring, validation pipeline

### Reddit
- **r/ClaudeAI**: "I built 10,000 skills for Claude. Here's what I learned"
- **r/programming**: "Open source library of 10K structured prompts across 39 domains"
- **r/Python**: "Claude Skills SDK — validate and score 10K+ AI prompts"

### Twitter/X
- Thread: "Top 10 skills that save me hours" with GIF demos
- Daily skill spotlight
- Progress updates on quality scores

### Dev.to
- Series: "Building a Bilingual AI Skills Library"
  1. Architecture & Design
  2. Quality Scoring System  
  3. Validation Pipeline
  4. Community Building

### Product Hunt
- **Tagline**: "10,000+ bilingual skills for Claude Code — the largest open library"
- **Key features**: 
  - 39 domains, EN + RU
  - Quality scoring (A–F)
  - Python + TypeScript SDK
  - 7.8s full validation
  - 93% test coverage
