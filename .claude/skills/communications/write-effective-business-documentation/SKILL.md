# Write Effective Business Documentation

> Create clear, concise, and professional business documents and communications

## Step-by-Step
1. Define document purpose and audience
2. Outline key points and structure
3. Write clear opening statement
4. Develop supporting arguments with evidence
5. Use formatting for readability
