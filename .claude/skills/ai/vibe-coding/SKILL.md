# Vibe Coding

> The art of AI-assisted development where you describe what you want and let AI write the code.

## Quick Start
```markdown
# Vibe Coding Workflow

1. **Idea Phase**: Describe what you want in plain English
   > "Build me a real-time chat app with rooms and emoji reactions"

2. **Scaffold Phase**: Let AI generate the entire project structure
   > "Create a Next.js app with WebSocket support, Prisma ORM, and Tailwind CSS"

3. **Iterate Phase**: Refine with conversational prompts
   > "Add typing indicators" → "Make messages persist to database" → "Add file sharing"

4. **Polish Phase**: Ask for specific improvements
   > "Add error boundaries" → "Optimize bundle size" → "Write unit tests"

5. **Review Phase**: Audit the generated code
   > "Check for security vulnerabilities" → "Review database schema normalization"
```

## Key Concepts
Vibe coding shifts from writing code to directing AI. Focus on what, not how. The key skills are clear specification, iterative refinement, and quality review. Treat AI as a senior engineer you're directing.

## When to Use
- Rapid prototyping and MVPs
- Learning new technologies by example
- Automating boilerplate and repetitive code
- Exploring architectural alternatives quickly

## Validation
1. Generated code compiles and runs without errors
2. Core features work as described in the initial spec
3. Security and edge cases are handled (AI often misses these)
