# public / private / hybrid cloud

**What it is**  
Публичное облако, приватный дата-центр или комбинация. 

**Why it matters**  
Регуляции, затраты, контроль данных. 

**Must know**  
Public: мульти-тенант, дешевле. Private: dedicated, дороже. Hybrid: часть on-prem, часть cloud. 

**Must be able to do**  
Спроектировать hybrid сеть (Direct Connect). 

**Where it is used**  
Public: стартапы. Private: банки, госсектор. Hybrid: enterprise с legacy on-prem. 

**Trade-offs**  
Public: +дешево, -контроль. Private: +контроль, -дорого. Hybrid: +гибкость, -сложность. 

**Common mistakes**  
Hybrid «потому что модно». Публичное для данных под strict регуляцией. 

**Interview check**  
Q: Зачем hybrid? A: Регуляции (данные on-prem) + масштаб облака. 

**Mini example**  
On-prem AD + AWS AD Connector. Direct Connect 1Gbps $200/мес.
