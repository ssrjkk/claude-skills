# zero trust

**What it is**  
Никому не доверять, проверять всё. 

**Why it matters**  
Периметр исчезает. 

**Must know**  
MFA везде. Верификация каждого запроса. 

**Must be able to do**  
Включить MFA для всех users. 

**Where it is used**  
Enterprise, удаленная работа. 

**Trade-offs**  
+Безопасность. -UX сложнее. 

**Common mistakes**  
MFA только для admins. 

**Interview check**  
Q: Zero Trust principle? A: Never trust, always verify. 

**Mini example**  
VPN -> Zero Trust Network Access (ZTNA).
