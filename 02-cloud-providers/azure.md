# Azure

**Ключевые сервисы**: Virtual Machines, AKS, Azure Functions, Blob Storage, Cosmos DB. 
**Сильные стороны**: Лучшая enterprise интеграция (AD), гибридное облако (Arc). 
**Слабые стороны**: Сложнее AWS для новичков, дороже для non-enterprise. 
**Типичные use cases**: .NET shops, enterprise с on-prem AD, регулируемые отрасли.
