| Containers | ECS / EKS | GKE | AKS |
| Serverless | Lambda | Cloud Functions / Cloud Run | Azure Functions |
| Object Storage | S3 | Cloud Storage | Blob Storage |
| Block Storage | EBS | Persistent Disk | Managed Disks |
| SQL DB | RDS | Cloud SQL | Azure SQL |
| NoSQL | DynamoDB | Firestore | Cosmos DB |
| Queue | SQS | Pub/Sub | Service Bus |
| Load Balancer | ALB/NLB | Cloud LB | Load Balancer |
| CDN | CloudFront | Cloud CDN | Azure CDN |
| DNS | Route 53 | Cloud DNS | Azure DNS |
| Monitoring | CloudWatch | Cloud Monitoring | App Insights |
| IAM | IAM | Cloud IAM | Azure AD / RBAC |
| Secrets | Secrets Manager | Secret Manager | Key Vault |
| VPC | VPC | VPC | Virtual Network |
