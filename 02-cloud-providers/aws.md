# AWS

**Ключевые сервисы**: EC2, ECS, EKS, Lambda, S3, RDS, DynamoDB, IAM. 
**Сильные стороны**: Самый зрелый (300+ сервисов), Graviton (ARM) дешевле на 20%. 
**Слабые стороны**: Сложнее для новичков, слабее enterprise интеграции vs Azure. 
**Типичные use cases**: Стартапы, general workloads, максимум сервисов.
