# GCP

**Ключевые сервисы**: Compute Engine, GKE, Cloud Functions, Cloud Storage, BigQuery. 
**Сильные стороны**: Лучший Kubernetes (GKE), BigQuery для petabyte-scale, глобальная сеть. 
**Слабые стороны**: Меньше сервисов чем AWS, слабее enterprise фокус. 
**Типичные use cases**: K8s-native, Data Science/ML, глобальные приложения.
