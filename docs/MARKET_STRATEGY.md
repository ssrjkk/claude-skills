## SEO Strategy

### Keywords to Dominate

```
High-volume (1K-10K searches/month):
- "Claude AI skills"
- "AI prompt library"
- "developer prompt collection"
- "FastAPI best practices"
- "React component library"

Mid-volume (100-1K searches/month):
- "Kubernetes debugging guide"
- "PostgreSQL optimization skills"
- "TypeScript patterns"
- "Pytest advanced patterns"

Long-tail (10-100 searches/month):
- "How to debug slow Kubernetes pods"
- "PostgreSQL query optimization secrets"
- "React hooks performance patterns"
```

### SEO Execution

```
1. Each skill = optimized landing page
   - URL: /skills/{domain}/{skill-name}
   - Meta description: 160 chars
   - H1: Skill name + context
   - Internal links: Related skills
   - JSON-LD schema markup

2. Blog content (weekly)
   - "Top 10 [Framework] skills"
   - "[Topic] patterns explained"
   - Case study: "How we saved 200 hours"

3. Backlink strategy
   - Dev.to guest posts (10+ per month)
   - HackerNews comments with links
   - Reddit community contributions
   - Podcast mentions
```
