# Roadmap

## Junior (0-2 years)

- Linux basics, networking
- IaaS/PaaS, VMs, S3
- IAM, security groups
- Docker basics
- CI/CD basics

## Middle (2-5 years)

- Containers orchestration (ECS/EKS)
- K8s basics
- Terraform/CloudFormation
- Observability (Prometheus, Grafana)
- Cost optimization

## Senior (5-8 years)

- Multi-account, hybrid cloud
- K8s advanced
- Well-Architected
- SRE practices (SLO, error budgets)
- Disaster Recovery

## Staff (8+ years)

- Multi-cloud strategy
- Architecture design
- Team leadership
- Cloud migration
- Cost governance
