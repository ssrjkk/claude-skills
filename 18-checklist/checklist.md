# Pre-Flight Checklist

## Before Deploy

- [ ] IAM least privilege
- [ ] Security groups: only needed ports
- [ ] Encryption at rest/transit
- [ ] Backups настроены
- [ ] Monitoring + alerts
- [ ] Cost budget set
- [ ] High availability (Multi-AZ)
- [ ] Tags добавлены
- [ ] Secrets не в коде
- [ ] Tests пройдены

## Daily Checks

- [ ] CloudWatch alarms
- [ ] Cost anomaly detection
- [ ] Security audit
- [ ] Backup status
