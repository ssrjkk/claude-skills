# Claude Skills - QA/Testing Automation

База скиллов для Claude.ai, сфокусированная на автоматизации тестирования QA.

## Структура

```
.claude/skills/
├── api-testing/
├── database-migration/
├── ci-cd-setup/
└── test-reporting/
```

## Скиллы

| Скилл | Описание |
|-------|----------|
| api-testing | Тестирование REST и GraphQL API с pytest и requests |
| database-migration | Управление миграциями PostgreSQL через Alembic |
| ci-cd-setup | Настройка пайплайнов GitHub Actions |
| test-reporting | Генерация отчетов Allure |
