# cloud-skills

Внутренняя инженерная база знаний для cloud-инженеров, SRE и архитекторов.

## Структура

| Папка | Содержание |
|-------|-----------|
| `01-core-fundamentals` | IaaS/PaaS/SaaS, regions, scalability, HA/DR, CAP, consistency |
| `02-cloud-providers` | AWS, GCP, Azure сравнение и mapping сервисов |
| `03-compute` | VMs, autoscaling, load balancing, serverless, containers |
| `04-networking` | VPC, subnets, security groups, peering, DNS, CDN |
| `05-security` | IAM, least privilege, secrets, compliance, zero trust |
| `06-storage` | Object, block, file storage, lifecycle, glacier |
| `07-databases` | SQL vs NoSQL, DynamoDB, RDS, Aurora, backups |
| `08-containers-k8s` | Docker, ECS/EKS/GKE, pods, services, ingress |
| `09-cicd` | CI/CD pipelines, GitHub Actions, ArgoCD, Blue/Green |
| `10-iac` | Terraform, CloudFormation, state management, modules |
| `11-observability` | CloudWatch, Prometheus, Grafana, tracing, alerts |
| `12-reliability` | SLA/SLO/SLI, error budgets, chaos engineering |
| `13-cost` | Cost optimization, budgets, reserved, spot, tagging |
| `14-architecture` | Well-Architected, patterns, anti-patterns |
| `15-scenarios` | Real-world задачи и решения |
| `16-interview` | Вопросы и ответы для собеседований |
| `17-skill-matrix` | Матрица компетенций по уровням |
| `18-checklist` | Pre-flight чеклисты для инженеров |
| `19-roadmap` | Путь развития от Junior до Staff |

## Быстрый старт

1. Начни с `01-core-fundamentals`
2. Выбери свой облачный провайдер в `02-cloud-providers`
3. Изучи compute/storage/networking
4. Пройди чеклист в `18-checklist`

## Принципы

- Только русский язык (кроме заголовков)
- Стрелки `->` вместо `→`
- Каждая тема: use-case, trade-offs, когда НЕ использовать
- Никакой воды, только практика
