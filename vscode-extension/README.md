# Claude Skills for VS Code

Browse, search, and install 10,000+ bilingual Claude Code skills directly from VS Code.

## Features

- **Skill Catalog** — Browse 10,000+ skills organized by 39 domains in the VS Code sidebar
- **Search** — Find skills by name, description, or tags
- **One-click Install** — Download SKILL.md files to your project's `.claude/skills/` directory
- **Installed Skills View** — See what's installed and open files directly
- **Skill Preview** — View skill metadata, description, and tags before installing

## Usage

1. Open the Claude Skills sidebar (book icon in activity bar)
2. Browse categories or use the search command
3. Click a skill to preview it
4. Install with one click

## Requirements

- VS Code 1.85+
- A workspace folder (to install skills into `.claude/skills/`)
